# Guia de Contribuição

Agradecemos o interesse em contribuir com a **ENEM API**!

## Diretrizes
1. O repositório visa ser leve, eficiente e focado em Cloudflare Workers + Hono.
2. Toda alteração de código deve ser feita via Pull Request apontando para a branch `main`.
3. Garanta que testes e checagem de tipos passem (`npm run typecheck` e `npm run test`).
4. Não inclua segredos, tokens de API ou dados privados em commits.
5. Qualquer ajuste em rotas ou contratos deve ser refletido em `openapi.yaml`.
